# 📊 Interactive Power BI Dashboard Portfolio

## 🧠 Overview

This repository contains a collection of interactive and visually engaging dashboards built using Microsoft Power BI Desktop. The project focuses on transforming raw datasets into meaningful insights through data modeling, visualization, and business intelligence techniques.

It demonstrates strong capabilities in data cleaning, DAX calculations, KPI tracking, and building user-friendly dashboards that support data-driven decision-making.

---

## 🎯 Purpose

The main goal of this project is to:

- Convert raw data into actionable insights  
- Build interactive and dynamic dashboards  
- Strengthen data analysis and visualization skills  
- Showcase real-world business intelligence capabilities  

---

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop  
- Power Query (Data Cleaning & Transformation)  
- DAX (Data Analysis Expressions)  
- Excel / CSV datasets  
- Data modeling & visualization techniques

## 📌 Key Features
